\section{Prior Work}
\label{sec:related}

Library design has often consisted of error prone PCR to sample various amino
acids at different positions. This can be done in a targeted way or more
generally over the entire scaffold. Many directed evolution campaigns often use
error prone PCR to build a large library. Many mutations are often deleterious
and modern tools like structure prediction allow us to filter out many of these
obviously harmful mutations. In addition gene fragment shuffling is another way
to go about making diverse libraries. Methods like SCHEMA from Frances Arnold's
group aimed to find the best points at which to split enzymes for combinatorial
shuffling~\cite{voigt2002schema,meyer2003schemalibrary}. More modern work like
that from Sarel Fleishman~\cite{khersonsky2018funclib} and SAMPLE from Phil
Romero~\cite{rapp2024sample} demonstrate how we can use combinatorial libraries
to do active learning style iteration. As autonomous labs are being developed
around the globe and we are preparing to scale data generation for building
better protein function predictors. We have a need for generating high fidelity
large scale libraries for evaluation. Here we will present an approach for
post-training ProteinMPNN~\cite{dauparas2022proteinmpnn} to propose protein
fragments which combine nicely with one another to create a high fidelity and
highly diverse library.
